# БОТОГРАД — Документация

## Запуск
```bash
cd server
npm install
npm start
# Открыть http://localhost:3001
```

## Сообщения (20 типов)
`[STATUS]` `[SPAWN]` `[PICKUP]` `[DAMAGE]` `[HEAL]` `[BUFF]` `[DEBUFF]` `[COMBO]` `[CRIT]` `[WAVE]` `[BOSS]` `[KILL]` `[LEVELUP]` `[QUEST]` `[TRADE]` `[LOOT]` `[EVENT]` `[SYNC]` `[ERROR]` `[SYSTEM]`

## Накопление
- **Ресурсы** — валюта улучшений
- **XP** — уровни (100 XP/ур)
- **Комбо** — серии подборов
- **Престиж** — каждые 10 уровней
- **Ключи** — доступ к сундукам

## Детерминизм
Карты, класс, паттерн боссов — всё предсказуемо по `hashCode(playerId)`.
